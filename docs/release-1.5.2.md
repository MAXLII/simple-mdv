# Simple Markdown Viewer 1.5.2

本版本修复含公式的表格显示，并支持使用 Windows 默认软件打开阅读器不支持的常见文档。

## 更新

- 修复表头或单元格公式中的绝对值竖线被误当作分列符，导致整张表显示为源码的问题。
- 点击 PDF、Office 文档、图片、音视频及常见压缩包链接时，先检查文件是否可访问，再交给系统默认软件打开。Markdown 和代码仍在阅读器内打开。
- 正确处理链接文件名中的中文、空格及编码后的特殊字符；文件不可访问、默认软件打开失败和锚点不存在时显示提示。
- 可执行文件和快捷方式不通过文档链接启动。

## 下载与升级

- Windows：`SimpleMarkdownViewerSetup-1.5.2.exe`，关闭阅读器后覆盖安装。
- `SHA256SUMS.txt` 提供安装包的 SHA-256。
- 本次不提供新版 Android APK；Android 用户可继续使用 1.5.0。

## 验证与限制

通过 JavaScript 自动化测试和 Windows 安装包构建。回归覆盖公式表格、默认软件分派、中文与共享路径、失败提示及安全限制。系统默认软件启动采用模拟接口验证，尚未完成最终安装包的安装交互和桌面目视复验。
