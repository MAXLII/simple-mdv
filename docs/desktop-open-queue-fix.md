# 桌面打开请求重复消费修复

2026-09-12：用户反馈启动自动打开同一份文档，关闭标签后立即重开。

根因是队列适配器调用了不存在的 `filesystem.removeFile`，而当前 Neutralino 6.9.0 库提供 `filesystem.remove`。打开成功后删除请求失败，350 ms 轮询再次消费该请求。已同时更正适配器和 nativeAllowList。

验证：`npm test` 全部通过，Windows 安装包构建成功。在工作区专用队列写入一次请求，实际原生程序打开 README 后请求文件消失；点击标签关闭按钮，经过多轮轮询仍保持空白；退出后用相同队列无文件参数启动，仍为空白页面。没有手动删除用户原有队列或修改用户文档。

新版覆盖安装后，遗留请求可能再打开一次，随后会被清理，关闭后不再重开。用户原有安装目录未修改。
